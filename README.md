# Student Performance Prediction System

## Overview

This machine learning project predicts whether a student will pass or fail based on:

- Study Hours
- Attendance
- Previous Scores

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Google Colab
- GitHub

## Project Workflow

1. Load Dataset
2. Explore Data
3. Preprocess Data
4. Train Logistic Regression Model
5. Evaluate Accuracy
6. Predict Student Performance
